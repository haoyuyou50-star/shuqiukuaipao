# 装配与交接

## 拿到文件先做什么

1. 在 Unity 里把 `models/` 拷到项目的独立美术目录，保持 FBX 导入单位为米；先确认 A01 绑定的球形碰撞直径是 **0.060 m**，再搭其他东西。FBX 按 Y-up 导出；下游朝向以本地 `IN → OUT` 的标记为准，不凭 Unity Transform 的正负号手工猜轴。
2. 不要给整个外观自动生成一个凸包。将 `COL_*` 节点设为不可见的碰撞代理，逐件设置 MeshCollider 或基础形状；托盘、坡和盒轨道仅在真实滚动面用代理。静态连续斜面可接 MeshCollider。跟随关节的移动件使用分段凸体/基础碰撞，不能用一个凸包盖住漏斗、锅口或弧形围边。
3. 带 `Trigger`/触发区语义的代理只设为触发，不当成实体阻挡。球用根节点同轴的 SphereCollider（半径 0.030 m），不求外壳不规则面与物理严格贴合；眼睛没有碰撞。
4. 保留父子层级。A08 盒盖挂在实际折线轴心上，轨道替换旋转时跟着盖子走。A11 铲体根是支点，A20 是落桌支座。A23 挡片围绕独立 X 轴转，开到位再放球。实际弹射速度、复位参数和所有粒子/音效交给程序。
5. 球体更换 `Potato_BODY` 材质即可表现四种状态；不换尺寸、不换眼睛、不用颗粒贴图。FBX 默认是初炸色，Blender 源文件保留四个色材质，预览图可作调色参考。

## 按关卡装配

| 批次 | 新增或首次使用 | 场景组装重点 |
| --- | --- | --- |
| 01 虫洞送餐 | A01 薯球、A04 酱碟、A05 环占位、A07 汉堡盒、A08 盒盖短坡、A09 薯条盒接球口 | A08 断口接环；A09 入口 228 mm，出口 100 mm。以 A09 抬 71 mm、酱碟向下游偏 85 mm 的测试支架摆法为基线。卷边和卡口不参加滚动碰撞。 |
| 02 裹粉 | A02 独立粉面、A10 浅餐盘、A19 楔形垫块 | 对齐 A19 的 `MOUNT_Tray` 并复制其倾角（8°），将 A02 父到 A10 的 `MOUNT_FlourInsert`。粉面和触发体跟盘体走，触发区无实体台阶。 |
| 03 初炸 | A03 炸锅、A06 弹板面、A23 挡片 | 锅体、油面、提示灯和装饰分开，进度 UI 看 `MOUNT_ProgressUI`。`POS_LaunchBallCenter` 与 `REF_LaunchVector` 定起点和竖直方向，不代表固定弹高。挡片的轴心与碰撞体同转。单独检查锅口接球和弹板，小节重试逻辑在引擎做。 |
| 04 复炸 | A11 长柄锅铲、A18 弧形围边、A20 转轴与支座、A21 限位、A22 配重 | A11 轴心放到 A20 的 `PIVOT`；用 A11 `LIMIT_CONTACT` 标记对准限位。A18 可与 A10 同根，保留出口。长短路实际耗时需在关卡里测。 |
| 通用与扩展 | A12 餐夹、A13 带嘴量杯、A14 滚筒槽、A15 直槽、A16 弧槽、A17 过渡坡、A24 星形脆片 | 都是分件模型。餐夹分岔、锅铲拨杆顶开盒桥、翻斗和慢速槽的受控联动由引擎实现。 |

## 文件和版本

- `Axx` 对应资产表编号，文件名稳定。每个 FBX 一项可复用资产；`models/` 不包含效果脚本、Blender 灯光和展示台。
- 整套 Blender 源稿以集合组织，主要装配标记为 Empty。库内数组摆放仅供检视；单体 FBX 导出时根已归零。源文件隐藏 `COL_*` 以便浏览，按需在 Outliner 展开。
- `docs/manifest.json` 记录的是应用 Blender 修改器后、未计剔除和实例化的三角数。不能把它当作整关面数或头显性能测试。
- 重跑：`blender -b -t 8 --python-exit-code 1 --python build/build_kit.py -- --skip-render`。不加 `--skip-render` 会输出未经排版的可再生渲染；如需重建图鉴，渲染后运行 `python3 build/compose_previews.py`（需要 Pillow 和 Noto Sans CJK）。
